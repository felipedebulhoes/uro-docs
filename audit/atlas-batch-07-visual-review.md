# Revisão Visual — Lote 07: Complicações e Revisão Cirúrgica

| Entrada | Decisão | Conteúdo de segurança clínica acrescentado |
|---|---|---|
| Nefrectomia parcial | Aprovar | Pseudoaneurisma/hemorragia tardia e resposta por embolização seletiva. |
| Prostatectomia radical | Aprovar | Extravasamento anastomótico e técnica robótica de reparo precoce. |
| RIRS | Aprovar | Esquema de avulsão ureteral e necessidade de reconstrução de resgate. |
| NLP | Aprovar | Fluxo de decisão para sangramento após NLP e embolização. |
| HoLEP | Aprovar | TC de perfuração capsular com extravasamento de irrigação. |
| RTU-P | Aprovar | TC de enfisema subcutâneo após microperfuração durante ressecção bipolar. |
| Hidrocelectomia | Rejeitar | Fotografia intraoperatória não esclarece de forma suficiente recidiva, hematoma ou infecção e tem exposição escrotal desnecessária. |
| Prótese peniana inflável | Aprovar | Via e princípio técnico de salvamento de infecção protética. |
| Reimplante ureteral | Aprovar | Cistograma de extravasamento pós-reconstrução como alerta de fístula/anastomose. |
